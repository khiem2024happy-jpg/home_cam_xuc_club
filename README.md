# Cảm Xúc Club — Hạ Long Landing Page

## Lưu ý quan trọng để ảnh và logo hiển thị 100%:
1. Logo đã được nhúng trực tiếp dạng Inline SVG trong `index.html`, đảm bảo **không bao giờ bị mất hay lỗi hiển thị**.
2. Toàn bộ 5 ảnh đã được đặt ngay tại thư mục gốc ngang hàng với `index.html` (và cả thư mục `images/`), kèm cơ chế tự động fallback kép.
3. Khi tải lên GitHub: Hãy chọn **toàn bộ các file** (`index.html`, 5 file ảnh `.jpg`, `vercel.json`) và kéo thả lên GitHub.
